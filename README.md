Энэ лабораторийн ажлаар Playwright ашиглан https://www.saucedemo.com
демо сайт дээр UI автомат тест бичсэн. Дараах 3 тестийг хамарсан:

Амжилттай нэвтрэх— зөв username/password ашиглан нэвтэрч, Products
  хуудас руу шилжсэнийг шалгасан.

Амжилтгүй нэвтрэх — буруу нууц үгээр нэвтрэхэд алдааны мессеж гарч
  буйг шалгасан.

Нэвтэрсний дараах үйлдэл — нэвтэрсний дараа бараа сагслаж, сагсны
  тоолуур зөв өөрчлөгдсөнийг шалгасан.

Тестийг --trace on горимоор ажиллуулж, trace viewer ашиглан алхам
бүрийг (screenshot, DOM snapshot, network хүсэлт) шалгаж үзсэн. Мөн
санаатайгаар нэг assertion-г буруу болгож, trace viewer дээр алдааг
хэрхэн мөшгөж болохыг туршиж үзсэн.


Playwright-ийн auto wait нь их цаг хэмнэсэн санагдсан бөгөөд selenium бодвол explicit wait байнга бичих шаардлагагүй болсон байсан. locator xpath ашиглахгүйгээр getByPlaceholder, getByRole, getByText ашигласан бөгөөд энэ нь илүү кодыг цэвэрхэн болгосон гэж бодож байгаа. мөн DOM дээр ямар нэгэн бүтэц өөрчлөхөд тэсвэртэй байгаа санагдсан. trance viewer дээр алдаа гарсан үед бүх талаас нь мэдээлэл харагдаж байгаа нь таалагдсан бөгөөд DOM, screenshot, network хүсжлт гээд бүгдийн нэг доороос нь харах нь  selenium харьцуулахад маш хялбар харахад ойлгомжтой байсан. Миний локал Debian орчин дээр ажилладаг ба WebKit хөтөч дээр тест ажиллуулахад системийн
dependency дутуугаас болж page.goto алдаа гарч байсан тул уг тестүүдийг
Chromium болон Firefox дээр баталгаажуулсан. Үүнээс харахад Playwright нь олон хөтчийг нэг командаар суулгах боломжтой ч зарим Linux орчинд системийн сангийн зөрчил гарч болохыг ойлгосон.
