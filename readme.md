Энэ лабораторийн ажлаар Playwright ашиглан [saucedemo.com](https://www.saucedemo.com)
демо сайт дээр UI автомат тест бичсэн. Дараах 3 тестийг хамарсан:

- **Амжилттай нэвтрэх** — зөв username/password ашиглан нэвтэрч, Products
  хуудас руу шилжсэнийг шалгасан.
- **Амжилтгүй нэвтрэх** — буруу нууц үгээр нэвтрэхэд алдааны мессеж гарч
  буйг шалгасан.
- **Нэвтэрсний дараах үйлдэл** — нэвтэрсний дараа бараа сагслаж, сагсны
  тоолуур зөв өөрчлөгдсөнийг шалгасан.

Locator-ын хувьд `getByPlaceholder`, `getByRole`, `getByText` зэрэг
орчин үеийн, тогтвортой locator-уудыг ашигласан бөгөөд XPath хэрэглээгүй.

Тестийг `--trace on` горимоор ажиллуулж, trace viewer ашиглан алхам
бүрийг (screenshot, DOM snapshot, network хүсэлт) шалгаж үзсэн. Мөн
санаатайгаар нэг assertion-г буруу болгож, trace viewer дээр алдааг
хэрхэн мөшгөж болохыг туршиж үзсэн.

Амжилттайн нэвтрээгүй: 

### Debian орчны асуудал

Локал Debian орчинд WebKit хөтөч дээр тест ажиллуулахад системийн
dependency дутуугаас болж `page.goto` алдаа гарч байсан тул уг тестүүдийг
Chromium болон Firefox дээр баталгаажуулсан.

## Playwright ба Selenium-ийн ялгааны ажиглалт

_(энд өөрийн 5-10 өгүүлбэрийн ажиглалтаа бич — жишээ нь: Auto-wait нь
Selenium-ийн explicit wait бичих хэрэгцээг хэрхэн арилгасан, Codegen
ашигласан туршлага, Trace viewer нь Selenium-ийн лог/screenshot-той
харьцуулахад дебаг хийхэд хэр хялбар байсан, олон хөтөч дэмжлэгийг нэг
командаар суулгах боломж гэх мэт өөрийн бодит туршлагаас бич.)_

## Ажиллуулах заавар

```bash
npm install
npx playwright install
npx playwright test
npx playwright show-report
```
